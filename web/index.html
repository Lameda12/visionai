Try the API — localhost:8000

    


      

        
Start the server

        
Requires Python 3.10+ and the project dependencies.

        
# one-command setup
make setup
make serve

        
# or manually
pip install -r requirements.txt
uvicorn api.server:app --reload

        
Then refresh this page — the status pill top-right will turn green.

      


      

        
API endpoints

        

          

            GET
            /health
            server status
          

          

            POST
            /detect
            YOLOv8 object detection
          

          

            POST
            /face
            DeepFace analysis
          

          

            POST
            /motion
            MOG2 motion diff
          

        

        
# test with curl
curl -X POST localhost:8000/detect \
  -F "file=@image.jpg" \
  -G -d "conf=0.5"

curl -X POST localhost:8000/face \
  -F "file=@portrait.jpg"
